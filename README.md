# Swagg - Portfolio

Meu portfolio pessoal em **React 18** + **Tailwind CSS** + **Three.js Shaders**

🌐 **Live**: [swaggadev.me](https://swaggadev.me)

## 🎨 Tech Stack

- **React 18** - Frontend Framework
- **Tailwind CSS v3** - Styling
- **Three.js + React Three Fiber** - 3D Shaders (Silk Animation)
- **Shadcn/ui** - Component Infrastructure
- **Create React App** - Build Tool

## 🚀 Features

✨ Silk Animation Background (GLSL Shaders)
🎯 Responsive Design
⚡ Production Optimized

## 📦 Instalação

```bash
cd swaggadev
npm install
npm start
```

## 🔨 Build & Deploy

```bash
npm run build
```

Depois copia `build/*` para a raiz do repo e faz push.
